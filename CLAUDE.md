# React demo simple app for Restaurant menu and order
- User as an Ordering Staff at the counter, pick a food from the menu list, add to the order list, then submit this order to the kitchen.

## Stack
- Frontend: React typescript
- Backend: Node
- Database: keep it simple, like an array of strings for the menu = ["Pasta", "Burger", "Noodle", "Beefsteak", "Banhmi", "Pizza"]

## Coding style
- Docstring (Google style) for public function/class.

## Architecture decisions
- Frontend and Backend is separated in different folders.
- Follow production standard.

## Plan-first policy
- Every feature deploy on >1 file -> MUST goto Plan Mode first.
